# 联合实验新区网页优化版

保留入口轮播、蓝白主色和全站共用导航、页脚与音乐播放器。

## 关于我们页面改版

- `gy.html` 改为大图首屏，向下依次展开「共建、创新、规划、基建、生态、水利、畅想」七个主题影像模块，使用项目现有的新区建设截图。
- 沿用全站蓝白配色、原有头部、主导航、页脚和音乐播放器。主题导航在主导航下方吸顶，可点击定位，并跟随阅读位置更新。
- 七个主题在进入视野较深处时逐个触发，模块用约 1.75 秒从下方 120px 上移渐显；照片解码后再用 2.2 秒独立上移、缩放并渐显，标题和说明分层错峰出现。锚点跳转不会提前播放目的模块的动画，慢速图片也不会挡住文字。
- 保留六周年官方宣传片、2019—2025 年发展历程、QQ 群及公众号信息。宣传片封面点击后才加载原 B 站播放器，同时暂停背景音乐；另保留 B 站直达链接，实际播放需要网络及 B 站服务可用。
- 已配置手机、平板和电脑的响应式样式。无 JavaScript 时主题内容直接可见；开启「减少动态效果」时保留轻柔淡入，关闭大幅位移、揭幕和视差。切页时清理该页的观察器、滚动监听、动画帧和视频播放实例。
- 已同步离线页面副本；可直接打开 `gy.html`，或从其他页面点击「关于我们」。本地双击模式仍沿用原项目的离线路由逻辑。

## 动画、分区与跟随栏更新

- 入口、主页 zy 与影像页 yx 的轮播改为参考站的整幅横向滑动并同步渐变：入口与影像页各 0.8 秒、主页 0.6 秒，每 5 秒自动切换。上一张从左进入、下一张从右进入；末张回首张直接向前滑一屏，不会反向越过中间画面。按钮、圆点、键盘与触摸使用同一过渡，快速连续点击按顺序完成，目标图下载并解码后才开始。系统“减少动态效果”也不会把轮播缩成硬切。入口 index 与主页 zy 均不再叠加格纹前置图。
- 全站 10 页接入 `assets/site-motion.js`：直接读取模块的视口位置触发动画，不依赖 IntersectionObserver；同屏模块按顺序错峰入场，快速滚动时直接显示已经越过的模块。关于我们保留七个主题与宣传片，使用完整的上移渐显和文字错峰动画。
- 站内切页先淡出当前正文，再切换内容并淡入；保留头部、主导航、页脚及同一个音乐播放器。每次进入任意页面都重新载入页面正文、重建轮播和筛选等交互，从顶部播放入场动画；浏览器后退、前进和再次点击当前页也不恢复旧滚动位置。明确点击页内锚点时仍定位到对应段落。连续快速点击导航会取消上一段切页动画，较早请求不能覆盖后来的页面。离开页面后清理监听、动画帧、定时器与动画对象。
- 分区页改为三大分区（东台莱德、采矿小镇、林沃森）与独立前哨站（眼镜岛）。使用现有实景、区徽及旗帜，移除不存在的旧图库图片；旗帜按竖版比例完整显示。三大分区分别介绍居住、工业、农林职能，眼镜岛单独标注前哨站并展示站徽与旗帜。
- 分区页含大图首屏、三分区速览、实景详情、前哨站及建设动态；吸顶导航随阅读位置更新。详情随滚动向上渐显，卡片保留轻微的缩放与箭头交互。手机、平板改为单列详情，区徽旗帜仍并排完整展示。
- 部门页职能目录与近期动态放在同一吸顶栏，电脑和平板随正文滚动。栏内内容超出窗口时可单独滚动；手机收为可展开的吸顶菜单，点击目录后自动收起，并为目标标题预留菜单与主导航的空间。
- HTML、共享脚本、页面样式及离线副本均使用同一资源版本标识，防止新旧动画脚本或样式混用。上传时请整体覆盖本包，包含新增的 `assets/site-motion.js`。

## 本轮页面与背景版更新

- 普通模块采用持续约 1.05—1.25 秒的上移渐显，关于我们的影像章节单独放缓至 1.75 秒并配合 2.2 秒照片动画；分区主题也逐个显现。切页的淡出与新页面上移淡入支持减少动态效果设置和无 WAAPI 的 CSS 后备动画。
- 档案管理改为大图首屏、可跟随的建设时间轴、两列档案封面与档案详情；八份档案每页展示四份，保留分页和大图弹窗，修复原本无效的两处图片路径。
- 影像记录改为大图轮播、四处风景索引、五张景点大图、六组合影版式；保留轮播、风景/合影切换和锚点，并将原来缺失的风景图换为项目现有实景。
- 新闻公告改为大图首屏、横向分类筛选、卡片信息流和焦点侧栏；保留八条公告、分类及分页。原有外部文章链接继续有效，旧占位链接指向站内相关栏目。
- 部门介绍改为大图首屏、职能概览、五组部门旗帜与职责卡片；目录及近期动态继续跟随滚动，手机端收为可展开的吸顶菜单。四页均提供手机、平板、电脑布局。
- 存档下载页改为城市大图首屏、当前版本卡、百度/夸克下载渠道、历代存档时间线、安装步骤与 FAQ，电脑、平板和手机布局分别适配。原页面中没有地址的历史版本、阿里云盘和整合包明确标注暂未开放，不再显示失效图片或空链接；保留原有有效网盘和 HMCL 启动器链接，外链在新标签页打开，站内音乐继续播放。网盘的实际文件内容需以提供方页面为准。

- 如需重新生成分类背景，可运行 `python3 tools/generate-backgrounds.py`。HTML、样式、脚本与离线副本已统一使用本轮资源版本标识。

## 使用

解压后整体上传 `Joint-Experimental-New-Area/` 里的文件，保持目录关系即可。也可双击 `index.html` 本地预览。

首次音乐播放仍需点击播放器的播放按钮。已经开始播放后，当前标签页里的普通站内导航不会重新加载音乐。手动刷新或另开标签页会创建新的网页实例。

新增歌曲只需把音乐放入 `music/`，再编辑 `music/playlist.js`。不需要给每个页面复制音乐文件。

## 代码位置

| 文件 | 用途 |
| --- | --- |
| `assets/site.css` | 公共头部、导航、页脚及入口处理 |
| `assets/mobile.css` | 手机和平板适配补充 |
| `assets/pages/*.css` | 各页面内容与响应式样式，按页面隔离 |
| `assets/editorial.css` | 档案、影像、新闻与部门共用的编辑式版式 |
| `image/backgrounds/` | 按页面分组的可替换 PNG 背景版 |
| `assets/site.js` | 无页面状态记忆的正文切换、地址历史、切页动画和锚点定位 |
| `assets/site-motion.js` | 全站滚动上移渐显、文字错峰及切页动画 |
| `assets/page-features.js` | 轮播、新闻筛选、档案分页和弹窗等页面功能 |
| `assets/music-player.css` / `assets/music-player.js` | 原 zy 播放器样式与行为 |
| `music/playlist.js` | 所有页面共用的歌单 |
| `image/department-backgrounds/` | 部门总览与六个部门的独立 PNG 背景，含文件对应与替换说明 |
| `assets/page-data.js` | 本地打开 HTML 时使用的正文及原有链接信息副本 |

编辑 HTML 正文、导航或页脚后，如果还需要本地双击预览，运行 `python3 tools/sync-offline-pages.py` 更新离线副本。正常网站模式读取 HTML 本身。只改 CSS、图片或音乐时无需运行此工具。
